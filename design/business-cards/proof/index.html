How a print preview works on the web

The browser still displays RGB. We render the complete card—including its embedded logo—then convert it from sRGB into CMYK using an ICC profile and convert those print colors back to sRGB for display. This is a profile-based conversion, not a desaturation filter.

Settings: relative colorimetric conversion with black-point compensation. White remains screen-relative; this view does not simulate paper white or absolute ink black. All comparison images have the same resolution and an embedded sRGB profile.

Adjusted palette: pink uses C0 M100 Y0 K0; lime uses C30 M0 Y100 K0. These changes are made in the CMYK separations before the screen preview is generated. The same recipes are applied to the logo and layout. Plum and cream keep their automatic conversions. The adjusted version also strengthens the watermark before conversion so its linework stays visible against the pink. The goal is a stronger print palette; some hue shift remains, and true fluorescent brightness is still unavailable.

The original SVGs remain unchanged. These preview PNGs are for comparison, not files to send to the printer. Once the printer supplies an ICC profile for the selected press and stock, we can regenerate the comparison for that process.
